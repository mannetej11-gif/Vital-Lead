# VitalLead - Healthcare Patient CRM 🏥

Professional healthcare patient management system with AI-powered scoring, JWT authentication, and real-time analytics.

## ✨ Features

✅ **Patient Dashboard** - Real-time patient overview  
✅ **AI Scoring Algorithm** - Automatic patient prioritization (0-100 scale)  
✅ **Call Intelligence** - Conversation tracking & sentiment analysis  
✅ **JWT Authentication** - Secure login with Bcrypt hashing  
✅ **Analytics** - Real-time data visualization  
✅ **Hospital Green & White Theme** - Professional healthcare aesthetics  

## 🏥 Design Highlights

- **Color Scheme:** Hospital Green (#1B5E46) + White
- **Typography:** Poppins (modern) + Playfair Display (elegant)
- **Components:** Cards, charts, tables, priority badges
- **Responsive:** Works on desktop & mobile

## 🚀 Quick Start

### Prerequisites
- Node.js >= 16.0.0
- Python >= 3.8
- npm >= 8.0.0

### Backend Setup

```bash
cd backend

# Create virtual environment
python3 -m venv venv

# Activate (macOS/Linux)
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run Flask server
python jwt_backend.py
